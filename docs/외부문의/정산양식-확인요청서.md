## 1. 요청 배경

지역아동센터 출결 관리 시스템에서 **월별 출결 자료를 내보내는 기능**을 만들었습니다.
이 자료가 보조금 정산 보고에 그대로 쓰일 수 있는지 확인이 필요합니다.

현재는 저희가 임의로 정한 칸 구성이며, **공식 양식을 구하지 못했습니다.**

## 2. 현재 내보내는 형식

CSV 파일. 윈도우 엑셀에서 바로 열립니다.

```
날짜,출석번호,이름,입실,퇴실,사유,입력방법,비고
2026-03-14,1,김민준,14:30,17:10,조퇴,관리자,병원 진료
```

| 칸 | 내용 | 값의 범위 |
|---|---|---|
| 날짜 | 출결 일자 | `YYYY-MM-DD` |
| 출석번호 | 센터 내부 아동 번호 | 정수 |
| 이름 | 아동 성명 | |
| 입실 | 등원 시각 | `HH:MM` 또는 빈칸 |
| 퇴실 | 하원 시각 | `HH:MM` 또는 빈칸 |
| 사유 | 출결 구분 | 출석 / 결석 / 조퇴 / 병가 / 기타 |
| 입력방법 | 누가 기록했나 | 키오스크(아동 직접) / 관리자(직원) |
| 비고 | 자유 입력 | |

## 3. 확인이 필요한 사항

### 3-1. 양식

- [ ] **공식 보고 양식이 따로 있는지.** 있다면 서식 파일을 받을 수 있는지
- [ ] 필수 항목 중 빠진 것이 있는지 (예: 급식 제공 여부, 프로그램 참여 여부, 보호자 확인란)
- [ ] 불필요하거나 넣으면 안 되는 항목이 있는지
- [ ] 제출 형식 (엑셀 / 한글 / 전용 시스템 입력)

### 3-2. 출결 구분

- [ ] **출석 / 결석 / 조퇴 / 병가 / 기타** 구분이 보고 기준과 맞는지
- [ ] 공식적으로 쓰는 구분 코드가 따로 있는지
- [ ] 결석 사유를 더 세분해야 하는지 (가정사정, 질병, 학교행사 등)
- [ ] 체류 시간 기준이 있는지 (예: 몇 시간 이상 있어야 출석 인정)

### 3-3. 기록의 신뢰성

- [ ] 아동이 직접 입력한 기록과 직원이 수기로 입력한 기록을 **구분해서 보고해야 하는지**
      (현재 `입력방법` 칸으로 구분하고 있습니다)
- [ ] 수기 수정 이력을 남겨야 하는지 — **현재 남기지 않습니다.** 요구된다면 기능 추가가 필요합니다
- [ ] 보호자 또는 센터장 확인 서명이 필요한지

### 3-4. 보관

- [ ] 출결 기록 법정 보관 기간
- [ ] 보관 기간 종료 후 파기 방법
- [ ] 퇴소 아동의 기록 처리 — 개인정보는 파기해야 하나 출결은 증빙으로 남겨야 할 수 있어
      **익명화 보존**이 가능한지

---

## 4. 저희 쪽 설계 원칙 (참고)

정산 근거임을 고려해 아래 두 가지를 지키고 있습니다.

1. **추정 시각을 자동으로 채우지 않습니다.** 퇴실 기록이 없는 날은 경고로만 표시하고,
   직원이 확인해 직접 입력합니다.
2. **재입력이 기존 시각을 덮어쓰지 않습니다.** 아동이 여러 번 눌러도 최초 기록이 보존됩니다.

이 방침이 보고 기준과 어긋나는 부분이 있다면 알려주시기 바랍니다.
