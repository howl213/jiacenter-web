|---|---|
| `db.sqlite3` | DB 파일. 아동 이름·연락처가 들어갈 수 있어 **절대 커밋 금지** (지금은 모의 값) |

## 2. 어디를 보면 되나 (찾기 표)

| 하고 싶은 일 | 볼 곳 |
|---|---|
| 화면 모양 바꾸기 | `src/center/templates/center/*.html`, `src/center/static/center/style.css` |
| 새 주소·화면 추가 | `src/center/urls.py` → `src/center/views.py` → 템플릿 |
| DB 표 바꾸기 | `src/center/models.py` (바꾸면 `makemigrations` 필요) |
| 운영/개발 설정 | `src/config/settings.py` (`DEBUG` 분기) |
| 서버 구성 이해 | `99.result/docs/아키텍처-설명서.html`, `99.result/architecture.svg` |
| 아직 안 끝난 일 | `99.result/docs/확인사항.md` |
| 작업 규칙 | `CLAUDE.md` |
| 자동 점검 돌리기 | `/verify` (= `harness_script/verify.sh`) |
