# 메모리 정리 제안 (2026-11-18, 적용 전)

메모리 파일은 이번 작업에서 직접 고치지 않았다. 아래는 사용자가 승인하면 할 일이다.
상시로 읽히는 것은 `MEMORY.md` 색인(약 1,800자)뿐이고, 개별 파일은 필요할 때만 읽힌다 — 그래서 합치거나 줄여도 상시 컨텍스트 효과는 작다. 목적은 낡은 근거를 없애는 것이다.

| 파일 | 문제 | 제안 |
|---|---|---|
| `team-repo-upload-hold` | 본문 대부분이 "보류·취약판 없음"이라는 옛 이야기(2026-11-16에 끝남) | 제외 목록(답안지·문의서·지침·`.claude/`, `db.sqlite3`·`logs/`)만 남기고 제목·설명을 "팀에 더 넘길 때 제외할 것"으로 |
| `vuln-publish-after-done` | 갱신 줄이 붙은 옛 내용, 포트폴리오 공개 시점은 사용자가 정한다는 것만 유효 | 두 가지 결정(답안지는 로컬에만, 공개 시점은 사용자)만 남김 |
| `closing-report-scope` | 규칙 본문이 CLAUDE.md 2절 3·4번과 같음 | 규칙은 "원문은 CLAUDE.md 2절"로 대체, 2026-11-11 지적 사례(Why)만 유지 |
