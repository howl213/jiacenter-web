## 1. 요청 배경

지역아동센터 출결 관리 시스템을 개발 중입니다. 아동이 센터에 도착하거나 하원할 때
보호자에게 알림을 보내 **출결 체크 누락을 줄이는 것**이 목적입니다.

현재 아동의 출결 입력률이 낮아 직원이 일일이 확인해 수기로 기록하고 있습니다.
보호자에게 알림이 가면 보호자가 아이에게 확인시켜 주는 효과를 기대합니다.

## 2. 사용하려는 범위

발송 유형은 세 가지입니다.

| 구분 | 발송 시점 | 문구(안) |
|---|---|---|
| 등원 | 아동이 입실 기록 시 | `{이름} 어린이가 {시각}에 센터에 도착했습니다.` |
| 하원 | 아동이 퇴실 기록 시 | `{이름} 어린이가 {시각}에 하원했습니다.` |
| 미입실 | 기준 시각까지 미입실 시 1회 | `{이름} 어린이가 아직 센터에 오지 않았습니다. 확인 부탁드립니다.` |

- 수신자: 센터 재원 아동의 보호자
- 발송량(추정): 아동 1인당 1일 최대 2~3건 — ※ 실제 재원 아동 수로 재산정 필요
- 광고성 내용 없음. 정보성 알림만.

## 3. 확인이 필요한 사항

### 3-1. 신청 자격과 절차

- [ ] 지역아동센터가 직접 신청 가능한지, 상위기관을 경유해야 하는지
- [ ] 신청에 필요한 서류
- [ ] 승인까지 소요 기간
- [ ] 비용 발생 여부

### 3-2. 템플릿

- [ ] 위 3개 문구를 사전 등록·심사받아야 하는지
- [ ] 심사 기준과 소요 기간
- [ ] 변수(`{이름}`, `{시각}`) 사용 가능 범위
- [ ] 반려 사유가 되는 표현

### 3-3. 발신번호

- [ ] 발신번호 사전 등록이 필요한지
- [ ] 센터 대표번호로 등록 가능한지

### 3-4. 기술 규격

- [ ] API 엔드포인트와 인증 방식
- [ ] 요청/응답 형식 문서
- [ ] 테스트(샌드박스) 환경 제공 여부
- [ ] 발송 실패 시 재시도 정책과 응답 코드
- [ ] 일/월 발송 한도

### 3-5. 개인정보

- [ ] 보호자 연락처를 전달할 때 별도 동의가 필요한지
- [ ] 개인정보 처리 위탁 계약이 필요한지
- [ ] 발송 기록 보관 기간 요건

## 4. 현재 구현 상태

승인 전이라 **실제 발송은 하지 않고 있습니다.** 보냈어야 할 내용만 DB에 기록합니다.

```python
# center/notify.py
def send_alimtalk(tel, template, **values):
    """API 승인 전이라 전송하지 않고 기록만 남긴다."""
    body = TEMPLATES[template].format(**values)
    if not tel:
        return None
    return NotifyLog.objects.create(tel=tel, template=template, body=body, sent=False)
```

승인되면 **이 함수 안에서만** 실제 호출을 추가하면 되도록 분리해 두었습니다.
연동 작업량은 크지 않습니다.
